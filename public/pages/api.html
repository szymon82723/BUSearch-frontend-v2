BUSearch — Dokumentacja API

Mapa
Publiczne endpointy API używane przez aplikację webową oraz aplikacje mobilne BUSearch (pozycje pojazdów na żywo, rozkłady, tablice przystankowe, planer podróży, wersjonowanie aplikacji mobilnej oraz bazę taboru Wiki).
https://api.busearch.pl/v1

0. Endpointy globalne i Aplikacja Mobilna (REST API v1)

1. Pojazdy i pozycje na żywo

GET https://api.busearch.pl/{city}/api/vehicles   (lub: https://api.busearch.pl/v1/cities/{city}/vehicles/live)

Żywe pozycje wszystkich pojazdów aktualnie widocznych na mapie (autobusy i tramwaje) wraz z kursem, azymutem i estymowanym opóźnieniem.

Parametry (query string)

ParametrTypOpis
linesstringOpcjonalny filtr linii po przecinku, np. ?lines=69,3,52
thinnumberOpcjonalne przerzedzanie gęstości markerów (dla widoków o małym zoomie)

Przykład

curl "https://api.busearch.pl/bydgoszcz/api/vehicles?lines=69,3"

Odpowiedź (fragment)

[
  {
    "linia": "69",
    "nr_boczny": "384",
    "lat": 53.12462,
    "lon": 18.00265,
    "predkosc": 34,
    "cel": "Tatrzańskie",
    "kierunek_deg": 65,
    "opoznienie_s": 120,
    "electric": true,
    "model": "Solaris Urbino 18 IV",
    "ts": "14:13:07"
  }
]
GET https://api.busearch.pl/{city}/api/buses   /   https://api.busearch.pl/{city}/api/trams

Wygodne aliasy zwracające wyłącznie autobusy lub wyłącznie tramwaje.

GET https://api.busearch.pl/{city}/api/vehicle/:id/etas

Lista przystanków pozostałych na trasie danego pojazdu wraz z szacowanym czasem przyjazdu (ETA w minutach), łącząca dane z tablic przystankowych z geometrią trasy. :id to nr_boczny pojazdu.

Przykład

curl https://api.busearch.pl/bydgoszcz/api/vehicle/384/etas

Odpowiedź (fragment)

GET https://api.busearch.pl/{city}/api/other-cities

Poglądowe pozycje pojazdów w sąsiednich miastach (np. Toruń, Trójmiasto) odświeżane w interwałach 5 minut.

2. Przystanki i tablice odjazdów

GET https://api.busearch.pl/{city}/api/stops   (lub: https://api.busearch.pl/v1/cities/{city}/stops)

Lista wszystkich przystanków w mieście lub wyszukiwarka po nazwie / identyfikatorze słupka (ID).

Parametry (query string)

ParametrTypOpis
qstringFraza wyszukiwania (nazwa lub ID przystanku), np. ?q=336 lub ?q=rondo
limitnumberMaksymalna liczba wyników przy wyszukiwaniu (domyślnie 10, max 50)

Przykład

curl "https://api.busearch.pl/bydgoszcz/api/stops?q=jagiellon&limit=5"

Odpowiedź (fragment)

[
  {
    "id": 9,
    "nazwa": "Rondo Jagiellonów",
    "lat": 53.12357,
    "lon": 18.00704,
    "lines": ["2", "3", "4", "5", "8", "9", "11"],
    "tram": true
  },
  {
    "id": 336,
    "nazwa": "Nakielska - Wrzesińska",
    "lat": 53.127035,
    "lon": 17.970427,
    "lines": ["36N", "56", "90"],
    "tram": false
  }
]
GET https://api.busearch.pl/{city}/api/stop/:id/departures

Tablica odjazdów live dla konkretnego słupka przystankowego. :id to identyfikator przystanku.

Parametry (query string)

ParametrTypOpis
linestringOpcjonalnie ogranicza odjazdy do jednej linii, np. ?line=8
afternumberOpcjonalnie znacznik czasu ms — zwraca odjazdy po danej godzinie
schedule1 | 01 = zwraca wyłącznie godziny rozkładowe GTFS (bez korekt GPS)

Przykład

curl "https://api.busearch.pl/bydgoszcz/api/stop/9/departures?line=3"

Odpowiedź

[
  {
    "linia": "3",
    "cel": "Łoskoń",
    "czas": "3min",
    "niskopodlogowy": true,
    "source": "live",
    "vehicleId": "ISKA5462"
  },
  { "linia": "3", "cel": "Wilczak", "czas": "14min", "niskopodlogowy": true }
]

vehicleId — przejście do właściwego pojazdu

Pole vehicleId pojawia się wyłącznie przy odjeździe live, gdy API jednoznacznie powiązało go z pojazdem na mapie. Jest to identyfikator z pola nr_boczny: może być numerem taborowym (np. 384) albo identyfikatorem wyliczonego kursu ISKA (np. ISKA5462). Jeśli pola nie ma, aplikacja nie powinna zgadywać ani wybierać najbliższego autobusu. 

const departures = await fetch(
  "https://api.busearch.pl/bydgoszcz/api/stop/9/departures"
).then((r) => r.json());

const id = departures[0].vehicleId;
if (id) {
  const vehicle = await fetch(
    `https://api.busearch.pl/bydgoszcz/api/vehicles?lines=${departures[0].linia}`
  ).then((r) => r.json()).then((vehicles) =>
    vehicles.find((v) => v.nr_boczny === id)
  );
  // Otwórz marker / szczegóły dokładnie tego pojazdu.
}

3. Linie, trasy i rozkłady

GET https://api.busearch.pl/{city}/api/lines

Kompletny wykaz wszystkich linii komunikacyjnych w mieście z przypisaniem do rodzaju i grupy rozkładowej.

Odpowiedź (fragment)

[
  {
    "id": "3",
    "number": "3",
    "type": "TRAM",
    "grupa": "Linie tramwajowe",
    "przystanki": "https://api.busearch.pl/bydgoszcz/api/line/3/stops"
  },
  {
    "id": "69",
    "number": "69",
    "type": "BUS",
    "grupa": "Linie autobusowe miejskie",
    "przystanki": "https://api.busearch.pl/bydgoszcz/api/line/69/stops"
  }
]
GET https://api.busearch.pl/{city}/api/line/:linia/stops

Lista przystanków dla linii w podziale na kierunki jazdy (warianty tras).

GET https://api.busearch.pl/{city}/api/line/:linia/route

Geometria trasy (współrzędne łamanych polilinii dla mapy) oraz przystanki dla wszystkich wariantów.

GET https://api.busearch.pl/{city}/api/line/:linia/timetable

Rozkład jazdy danej linii dla wybranego słupka przystankowego (warianty + tabele Dni powszednie / Soboty / Niedziele i święta).

Parametry

ParametrWymaganyOpis
stopTakID słupka przystankowego, np. ?stop=9

4. Planer podróży i geokodowanie

POST https://api.busearch.pl/{city}/api/polaczenia   (lub: https://api.busearch.pl/v1/cities/{city}/planner/journey)

Wyszukiwarka połączeń komunikacji miejskiej i kolejowej z uwzględnieniem przesiadek i dojść pieszych.

Treść żądania (JSON)

{
  "from": { "stopId": 9 },
  "to": { "lat": 53.1450, "lon": 18.0650 },
  "maxPrzesiadki": 2,
  "ksztalt": false
}

Parametr ksztalt: false pozwala pominąć szczegółową geometrię łamanych tras, redukując rozmiar odpowiedzi o ponad 80%.

GET https://api.busearch.pl/{city}/api/geocode   /   https://api.busearch.pl/v1/geocoding/search

Geokodowanie adresów w obszarze aglomeracji (OpenStreetMap Nominatim) oraz geokodowanie odwrotne.

Przykład

curl "https://api.busearch.pl/bydgoszcz/api/geocode?q=Gdańska+10"

5. Aplikacja mobilna, Radar, Trasy i Przystanki

GET https://api.busearch.pl/{city}/api/app/live/vehicles   /   https://api.busearch.pl/{city}/api/app/vehicles/precise

Niefiltrowany, pełny strumień telemetryczny o wysokiej precyzji GPS dla aplikacji natywnej (azymut, prędkość, stan ruchu, metadane taboru i linki do trybu stalkera).

GET https://api.busearch.pl/{city}/api/app/radar   (lub: https://api.busearch.pl/v1/cities/{city}/vehicles/radar)

Radar pojazdów w pobliżu użytkownika („Co koło mnie jedzie?”). Wylicza odległość w metrach (dystans_m), czas dojścia pieszego (czas_dojscia_pieszego_min) oraz czy pojazd zbliża się pod kątem do użytkownika (kierunek_do_mnie).

GET https://api.busearch.pl/{city}/api/app/trasa/:linia   /   https://api.busearch.pl/{city}/api/app/line/:linia/route

Geometria trasy i polilinie dla mobilnej mapy (MapLibre / Google Maps / Mapbox). Zwraca warianty kierunkowe, współrzędne łamanych ksztalt_trasy: [[lat, lon], ...], uporządkowaną sekwencję przystanków oraz pozycje autobusów jadących obecnie na tej trasie.

Przykład

curl "https://api.busearch.pl/bydgoszcz/api/app/trasa/69"
GET https://api.busearch.pl/{city}/api/app/pojazd/:id/trasa   /   https://api.busearch.pl/{city}/api/app/vehicle/:id/route

Trasa konkretnego autobusu/tramwaju ze statusem miniętych vs nadchodzących przystanków, aktualnym postępem procentowym kursu i szacunkiem czasu ETA.

GET https://api.busearch.pl/{city}/api/app/przystanki   /   https://api.busearch.pl/{city}/api/app/stops

Lista przystanków z obsługą wyszukiwania tekstowego (?q=Jagiellon lub ID ?q=336), geolokalizacji w promieniu (?lat=...&lon=...&promien=800) oraz filtrowania po liniach i typach transportu.

GET https://api.busearch.pl/{city}/api/app/przystanek/:id/odjazdy   /   https://api.busearch.pl/{city}/api/app/stop/:id/departures

Wirtualna tablica LCD dla wybranego słupka przystankowego. Zwraca dynamiczne odliczanie w sekundach (odjazd_za_sekund), opóźnienie, wskaźnik pozycji live oraz linki do śledzenia nadjeżdżającego taboru.

Przykład

curl "https://api.busearch.pl/bydgoszcz/api/app/przystanek/9/odjazdy"
GET https://api.busearch.pl/{city}/api/app/stalk/:id

Tryb stalkera dla wybranego numeru bocznego (pełna telemetria, postęp kursu, minięte/kolejne przystanki, ETA do pętli i dane techniczne taboru z Wiki).

GET https://api.busearch.pl/{city}/api/app/statystyki-live   /   https://api.busearch.pl/{city}/api/app/widget/podsumowanie

Globalne statystyki punktualności i prędkości floty w czasie rzeczywistym oraz lekki feed dla widgetów Android / iOS.

GET   POST   PUT https://api.busearch.pl/{city}/api/app/ulubione

Synchronizacja ulubionych przystanków dla widgetów pulpitu i aplikacji mobilnej na podstawie identyfikatora klienta (bez logowania).

6. Wiki taboru i baza wiedzy

GET https://api.busearch.pl/{city}/api/wiki/lookup

Szybkie wyszukiwanie pojazdu po numerze bocznym, ID lub tablicy rejestracyjnej (np. ?q=384).

GET https://api.busearch.pl/{city}/api/wiki/:id

Szczegółowa karta pojazdu: model, rok produkcji, patron, notatki, galeria zdjęć z koordynatami, usterki oraz pełna historia edycji.

GET https://api.busearch.pl/{city}/api/wiki/recent

Feed 500 ostatnich zmian w taborze (nowe zdjęcia, edycje numerów, patroni, opisy).

GET https://api.busearch.pl/{city}/api/wiki/photos-map

Lista wszystkich zdjęć taboru posiadających współrzędne GPS - do wyrysowania na mapie punktów fotograficznych.

7. Komunikaty i ogłoszenia

GET https://api.busearch.pl/{city}/api/announcements

Aktualne komunikaty dyspozytorskie, ostrzeżenia o utrudnieniach w ruchu i zmianach tras.
