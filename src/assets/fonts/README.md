# Roboto

Roboto variable WOFF2, Latin and Latin Extended subsets, downloaded from the Google Fonts CSS API on 2026-09-22. Used at weights 400 and 500 in the navigation drawer. Latin Extended includes Polish characters.

Source: https://fonts.googleapis.com/css2?family=Roboto:wght@400;500&display=swap
